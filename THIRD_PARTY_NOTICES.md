## Bundled in the Windows executable

The single-file Windows executable contains the Python interpreter and the packages above (except Matplotlib and
the development tools), frozen with [PyInstaller](https://pyinstaller.org/). Its `LICENSES` folder holds the texts
of this repository's `LICENSES/` plus `third-party/`: the unchanged license and notice files of every bundled
package and of Python, with `INVENTORY.txt` listing their exact versions (generated by `tools/build_windows.py`).

| Component | License in the executable |
|---|---|
| Python and its standard library | PSF License Version 2 and the notices it contains |
| Qt for Python (PySide6, shiboken6) and the Qt libraries | LGPL-3.0 — [LICENSES/LGPL-3.0.txt](LICENSES/LGPL-3.0.txt), which incorporates [LICENSES/GPL-3.0.txt](LICENSES/GPL-3.0.txt) |
| pyqtgraph, gregorithm | MIT |
| NumPy, SciPy | BSD-3-Clause and the licenses of their bundled components |
| PyArrow | Apache-2.0 with its NOTICE file |
| PyInstaller bootloader | GPL-2.0-or-later with the bootloader exception, which allows distributing the executable under any license |

**Qt and the LGPL.** SparkBox uses the open-source LGPL-3.0 option of Qt for Python. The Qt and PySide6 libraries are
used unmodified and remain separate files: on first start the executable extracts them to
`%LOCALAPPDATA%\SparkBox\app\<build id>\SparkBox\_internal`, where they can be replaced with compatible modified
versions. No restriction is imposed on such modification or on reverse engineering for debugging it. The
corresponding source code of the exact Qt for Python version listed in `INVENTORY.txt` is available from
[download.qt.io](https://download.qt.io/official_releases/QtForPython/) and the Qt source from
[download.qt.io](https://download.qt.io/official_releases/qt/); SparkBox's own source is this repository, and the
executable can be rebuilt with `tools/build_windows.py` (see [packaging/README.md](packaging/README.md)).
The `LicenseRef-Qt-Commercial` text found among the PySide6 files is upstream material retained unchanged; this
release does not use the commercial license.

The launcher that shows the startup banner runs on the .NET Framework that ships with Windows; the framework is not
redistributed.

## Methods

The histogram dQ/dV methods and the voltage reconstruction shown by SparkBox are computed by
gregorithm following E. Flores and S. Clark, "Simple and Comparable Computation of Incremental
Capacity Curves", *J. Electrochem. Soc.* 173 (2026) 120520, doi:10.1149/1945-7111/ae7e5c.
