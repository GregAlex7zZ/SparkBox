# Security policy

## Supported versions

SparkBox is in its 0.x series. Security fixes are applied to the latest version only.

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub's **Report a vulnerability** button in the
repository's *Security* tab (private vulnerability reporting). Do not open a public issue, publish
details or attach private battery data or credentials.

Include the affected version, platform, impact, reproduction steps and, if possible, a minimal
synthetic input file. Reports are handled on a best-effort basis.

## Scope

SparkBox is an offline desktop application. It does not access the network or send telemetry. It
reads only the files you open, writes results below its results folder and exports only where you
choose. Please report any behaviour contrary to this.
